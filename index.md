# Política de privacidad

**Última actualización:** 16 de octubre de 2026

Esta política describe cómo la aplicación **Psicología Desconocida** (la "Aplicación") trata los datos cuando se autoriza su acceso a una cuenta de Google/YouTube. La Aplicación es una herramienta interna creada y utilizada por el responsable del canal de YouTube [@PsicologiaDesconocida](https://www.youtube.com/@PsicologiaDesconocida) para gestionar su propio canal.

## Uso de los Servicios de API de YouTube

La Aplicación utiliza los Servicios de API de YouTube. Al utilizar la Aplicación, aceptas quedar vinculado por los [Términos de servicio de YouTube](https://www.youtube.com/t/terms). El tratamiento de datos por parte de Google se rige por la [Política de privacidad de Google](https://policies.google.com/privacy).

## Datos a los que accede la Aplicación

Con tu autorización, la Aplicación puede acceder a la información de tu canal de YouTube necesaria para gestionarlo, por ejemplo: datos básicos del canal, vídeos, metadatos (títulos, descripciones, etiquetas, miniaturas), listas de reproducción y estadísticas del canal.

## Cómo se usan los datos

Los datos se usan exclusivamente para gestionar el canal del propietario (por ejemplo, subir vídeos, editar metadatos y consultar estadísticas). No se usan con fines publicitarios ni para crear perfiles de usuarios.

## Almacenamiento y compartición

- Los tokens de acceso de OAuth se guardan solo en el equipo del propietario de la Aplicación, y nunca se comparten con terceros.
- La Aplicación no vende, alquila ni comparte datos de usuario con terceros.
- Los datos obtenidos de la API no se almacenan más tiempo del necesario para la tarea que se está realizando.

## Revocar el acceso y eliminar datos

Puedes revocar el acceso de la Aplicación en cualquier momento desde la [página de seguridad de tu cuenta de Google](https://myaccount.google.com/connections). Para solicitar la eliminación de cualquier dato almacenado, escribe al correo de contacto indicado abajo; la solicitud se atenderá en un plazo máximo de 30 días.

## Cambios en esta política

Esta política puede actualizarse. La fecha de la última actualización aparece al principio de esta página.

# Privacy Policy (English)

**Last updated:** October 16, 2026

**Psicología Desconocida** (the "App") is an internal tool built and used by the owner of the YouTube channel [@PsicologiaDesconocida](https://www.youtube.com/@PsicologiaDesconocida) to manage that channel.

- **YouTube API Services:** The App uses YouTube API Services. By using the App you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). See also the [Google Privacy Policy](https://policies.google.com/privacy).
- **Data accessed:** With your authorization, the App may access the YouTube channel information needed to manage it: basic channel data, videos, metadata (titles, descriptions, tags, thumbnails), playlists and channel statistics.
- **Use:** Data is used only to manage the owner's channel (e.g. uploading videos, editing metadata, reading statistics). It is not used for advertising or profiling.
- **Storage and sharing:** OAuth tokens are stored only on the App owner's computer. User data is never sold, rented or shared with third parties, and API data is kept no longer than needed for the task at hand.
- **Revoking access and deletion:** Revoke access at any time from your [Google Account connections page](https://myaccount.google.com/connections). To request deletion of any stored data, email the address below; requests are handled within 30 days.
- **Contact:** narcedinlopezleyva@gmail.com
